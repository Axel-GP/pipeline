# Internationalization Notes

- Add a new locale by creating `lang/xx/` subfolders (copy `home.php`, `ui.php`, etc.) and translating the text keys inside.
- Update `config/locales.php` so the new locale appears in the `available` array; the route group (`{locale}` prefix) and middleware will then accept it automatically.
- Extend the translation arrays used by the homepage, taxistas page, legal/privacy/cookies summaries, and `partials/ui.php` for menu/footer labels and the captcha messages.
- The new language will be included in the navbar selector automatically by reading `config('locales.available')` and `lang.ui.language_names`.
- If you add language-specific assets or text for other pages, update the new locale files and ensure `LandingController` can deliver the correct view in that locale.
